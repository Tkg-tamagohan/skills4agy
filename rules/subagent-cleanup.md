# 使い切った非 browser サブエージェントは報告後に終了する

`research` や `self` などのサブエージェントは完了後も明示的に終了するまで `idle` 状態でリストに残り、ユーザーには稼働中や連係漏れに見えやすい。
結果の統合が終わって再利用しないサブエージェントは、ユーザーへ報告する前に `manage_subagents` で終了する。

## 手順

1. 起動したサブエージェントから結果を受領し、内容を取り込んだことを確認する。
2. 追加の `send_message` を行う予定がなければ、`manage_subagents` の `kill` または `kill_all` で対象を終了してからユーザーへ報告する。

## 対象外

- `browser` サブエージェント（再利用のため `idle` のまま残す規約があるため）
- 後続ターンで `send_message` により継続作業やフォローアップを行う予定があるサブエージェント
